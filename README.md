# Generatore Casuale

Interfaccia ispirata a random.org: numeri interi (con esclusioni), sequenze, mescolamento di liste, moneta, dadi e password.
La casualità viene da `crypto.getRandomValues` del browser, con campionamento senza bias.

Apri `index.html` nel browser: non serve installare nulla.

Nel campo **Numeri da escludere** puoi scrivere valori singoli e intervalli, ad esempio `7, 13, 20-30`.
